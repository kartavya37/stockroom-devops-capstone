StockRoom release {{ .Release.Name }} is installed in the namespace {{ .Release.Namespace }}.

1. Look at the Pods:

     kubectl get pods -n {{ .Release.Namespace }}

2. Open the application:
{{- if .Values.ingress.enabled }}

     Add this line to the file /etc/hosts:
       <INGRESS_IP>  {{ .Values.ingress.host }}

     Then open: http://{{ .Values.ingress.host }}
{{- else }}

     kubectl port-forward -n {{ .Release.Namespace }} svc/{{ include "stockroom.fullname" . }}-frontend 8080:{{ .Values.frontend.service.port }}

     Then open: http://localhost:8080
{{- end }}

3. Look at the metrics:

     kubectl port-forward -n {{ .Release.Namespace }} svc/{{ include "stockroom.fullname" . }}-backend 8000:{{ .Values.backend.service.port }}
     curl http://localhost:8000/metrics
